### 1-1. Siemens Industrial Edge管理アプリケーションの「Node2Shell」脆弱性が実悪用、CISA KEVに追加（CVE-2026-111497）

- 出典: Siemens ProductCERT（SSA-443410）/ Viakoo「Daily OT Security News」（Security Boulevard転載）/ Akamai研究ブログ / OffSeq
- URL: https://cert-portal.siemens.com/productcert/html/ssa-443410.html ／ https://securityboulevard.com/2026/10/daily-ot-security-news-october-31-2026/ ／ https://www.akamai.com/blog/security-research/inside-node2shell-closer-look-cve-2026-111497
- 公開日: Siemensアドバイザリ 2026-10-30（元となるCISA KEVカタログ追加は2026-10-27）

**要約（3行以内）**
Google製圧縮ライブラリ「Brotli」のデコーダに存在するアウトオブバウンド書き込み脆弱性（CVE-2026-111497、通称「Node2Shell」）が、Siemens Industrial Edge Hub／Industrial Edge Management Cloudおよび関連する複数の管理アプリケーションに影響。CISAは本脆弱性が実際に悪用されていることを確認し、KEVカタログに追加しました。該当アプリケーションには執行時点で修正パッチが存在せず、SiemensはCommon Configurator on Deviceの停止や該当アプリケーションのアンインストール等の緩和策を推奨しています。

**やさしい要約**
工場のデジタル管理に使う「Industrial Edge」というSiemens製のソフトに、データの圧縮・展開処理の不具合が原因でハッカーが悪意のあるコードを実行できてしまう弱点が見つかりました。すでに実際の攻撃で使われていることが確認されており、しかも今のところ直せる修正プログラムがない製品があるため、使っている現場は回避策（機能停止やファイアウォールでの保護）で対応するしかない状況です。

**当社ビジネスへの影響**
- 実悪用が確認された脆弱性でパッチが未提供という点で緊急性が高く、**Nozomi**によるOT資産の可視化・脅威検知（該当製品の使用有無の把握、異常通信の検知）の提案に直結。
- 恒久対策までの「仮の守り」として、**Dispel**のセキュアリモートアクセスや境界保護、**TXOne**のエンドポイント/ネットワーク防御（該当アプリケーションを停止する代替の防御層）の提案余地が大きい。
- Siemens Industrial Edgeを導入している既存顧客には個別のアラート配信が必要。

**推奨アクション**
- Siemens Industrial Edge（Hub／Management Cloud／管理アプリケーション群）を導入している顧客への緊急アラート配信。
- 該当資産の棚卸しと、修正パッチ提供までの緩和策（Common Configurator停止、ファイアウォール/WAFによる保護、該当アプリのアンインストール）の実施支援を提案。

### 1-2. オープンソース制御システムソフト「EPICS Base」に重大脆弱性、Critical Manufacturingセクターに影響（CVE-2026-114595〜114598）

- 出典: CISA ICSアドバイザリ（ICSA-26-300-01）/ SecurityWeek / The Register / OpenCVE
- URL: https://www.cisa.gov/news-events/ics-advisories/icsa-26-300-01 ／ https://securityweek.com/long-hidden-flaws-patched-in-epics-research-facility-control-software
- 公開日: 2026-10-27

**要約（3行以内）**
研究施設・加速器・一部の産業制御システムで広く使われるオープンソースソフト「EPICS Base」（7.0.10以下）に4件の脆弱性が発見されました。うち1件は整数オーバーフローによるヒープ領域のアウトオブバウンド書き込みで、リモートからのコード実行につながる可能性があるとされ、CVSS v3.1で9.8（Critical）と報告されています。修正版7.0.11が同日リリースされました。

**やさしい要約**
研究機関や一部の工場で使われている、機械を細かく制御するための基盤ソフトに、外部から不正なデータを送るだけで乗っ取られかねない重大な欠陥が見つかりました。すぐに攻撃された形跡はないとされていますが、直すための新しいバージョンが用意されています。

**当社ビジネスへの影響**
- EPICSは一般的な工場OTというよりも研究施設・大学・一部の重要インフラで使われるニッチな制御基盤ですが、該当資産を持つ顧客（研究機関、大学、エネルギー関連研究施設等）には影響大。
- **セキュリティアセスメント**における「使用ソフトウェア資産の洗い出し」の重要性を訴求できる事例。
- **Nozomi**による制御システムプロトコル監視・資産管理の対象拡大の文脈でも参照可能。

**推奨アクション**
- 研究機関・大学・エネルギー関連顧客向けに、EPICS Base利用有無の確認と7.0.11へのアップデート状況のヒアリングを実施。

### 1-3. Hitachi Energy製品（TRO600／CoreTec）に複数脆弱性、認証回避・任意ファイル読み取り・OSコマンドインジェクション

### 1-4. Siemens Mendix SAMLモジュールにSAML署名検証の不備、リプレイ攻撃で不正アクセスの恐れ（CVE-2026-89209）

- 出典: CISA ICSアドバイザリ（ICSA-26-302-01、推定）/ OpenCVE / Siemens ProductCERT
- URL: 参考 https://app.opencve.io/cve/CVE-2026-89209
- 公開日: 2026-10-26頃

**要約（3行以内）**
Siemens製の業務アプリ開発プラットフォーム「Mendix」のSAML認証モジュールにおいて、正当なSAML応答を再送（リプレイ）することで未認証の攻撃者が不正にアクセスできる脆弱性が判明しました（CVSS概算7.6）。過去にも同モジュールで同種の署名検証不備が複数回報告されています。

**やさしい要約**
社内システムのログイン認証に使われる仕組みの一部で、一度使われた「本人確認の証拠」を盗んで再利用すると、本人になりすましてログインできてしまう不具合です。

**当社ビジネスへの影響**
- Mendixは主にIT領域の業務アプリ基盤であり、直接的なOT資産ではないものの、OT環境の監視・管理アプリがMendix基盤上に構築されている場合はIT/OT境界のリスクとして関連。
- 認証基盤の脆弱性管理という観点で**セキュリティアセスメント・コンサル**サービスの一般的な提案材料。

**推奨アクション**
- Mendix SAMLモジュールを使用するシステムがないか既存顧客へ確認し、該当する場合はパッチ適用状況のヒアリングを実施。

### 2-2. AnthropicのClaude Code拡張機能の改ざん版がCursorマーケットプレイス経由で配布、開発者端末にSSHバックドア

- 出典: BleepingComputer / Help Net Security / IT-Connect
- URL: https://www.bleepingcomputer.com/news/security/malicious-claude-code-extension-on-cursor-planted-ssh-backdoors/ ／ https://www.helpnetsecurity.com/2026/10/30/claude-code-extension-ssh-backdoor/
- 公開日: 2026-10-29〜30

**要約（3行以内）**
AnthropicのAIコーディング支援ツール「Claude Code」の拡張機能の改ざん版（バージョン2.1.313）が、コードエディタ「Cursor」のマーケットプレイス上で約11時間公開され、最大5,000人の開発者が影響を受けた可能性があるとCursorが発表。拡張機能読み込み時に自動実行されるスクリプトが、永続的なSSHバックドアを端末に設置する仕組みでした。Microsoft純正のVS Code Marketplaceは関与していません。

**やさしい要約**
AIを使ってプログラムを書く際に使う拡張機能の「偽物」が、別の開発ツール（Cursor）のアプリストアに紛れ込み、最大5,000人の開発者のパソコンに、外部から遠隔操作できる裏口（バックドア）が仕掛けられてしまいました。ただの拡張機能の削除だけでは裏口が残る恐れがあるため、専用の駆除手順が必要とされています。

**当社ビジネスへの影響**
- 開発者ツール・AIツールのサプライチェーンリスクが現実化した事例であり、ソフトウェアサプライチェーンセキュリティに関する**セキュリティアセスメント・コンサル**の提案材料として有効。
- 自社や顧客企業内でCursor／Claude Code等のAI開発ツールを利用している場合、該当バージョンの確認と駆除対応の支援ニーズが発生しうる。

**推奨アクション**
- 社内でCursor・Claude Code拡張機能を利用している部署があれば、バージョン確認（2.1.314以降への更新）と不審なSSH鍵・プロセスの有無を確認。
- 顧客向けにAI開発ツールのサプライチェーンリスクに関する注意喚起を検討。

## 3. 総括

- 今回の調査期間では、OT領域において**実際に悪用が確認された脆弱性（Siemens Node2Shell／CVE-2026-111497）**が最大のトピックでした。パッチが未提供のまま実悪用されている点は、既存顧客への緊急アラートの優先候補として扱うべきです。
- 業界全体では、AI関連ツール（開発支援AI、分析AI）を狙った／悪用したサプライチェーン型の攻撃が複数確認されており、「AI時代のサプライチェーンリスク」という観点が今後のコンサル提案のテーマとして有望です。
- 本レポートの一次情報裏取りについては、本セッションの実行環境からCISA・Nozomi・Dark Reading等の主要サイトへ直接アクセスできなかった制約があるため、重要な意思決定（顧客への正式なアラート配信等）の前には、必ずCISA公式アドバイザリページ等の一次情報での再確認を推奨します。
