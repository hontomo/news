### 1-1. NIST、OTセキュリティガイド改訂版「SP 800-82 Rev.4」のドラフトを公開、パブリックコメント期限は11/30

- 出典: SecurityWeek
- URL: https://www.securityweek.com/ot-security-guidance-nist-drafts-updated-guide-cisa-fbi-advise-on-ics-integrators/
- 公開日: 2026年11月中旬（コメント期限 2026-11-30）

**要約（3行以内）**
NISTが産業用制御システム（ICS/OT）セキュリティの標準ガイド「Special Publication 800-82」の第4版ドラフトを公開し、パブリックコメントを11月30日まで募集しています。同時期にCISAとFBIは、重要インフラ事業者がサードパーティのICSインテグレーターと連携する際のリスクに関するファクトシートも公表しました。

**やさしい要約**
工場や発電所などの機械を安全に守るための「公式な教科書」が、米国政府機関によって新しく書き直されようとしています。意見を言える期間は11月30日までで、業界の意見が反映される最後のチャンスです。

**当社ビジネスへの影響**
- SP 800-82 Rev.4は国内外のOTセキュリティ**アセスメント・コンサル**の評価基準・提案書の参照フレームワークとして今後広く使われる可能性が高く、内容の早期把握は提案力強化に直結する。
- サードパーティICSインテグレーターのリスクに関するCISA/FBIファクトシートは、当社が提供する**セキュリティアセスメント**（委託先・サプライヤー評価を含む）の訴求材料として有効。

**推奨アクション**
- ドラフト版SP 800-82 Rev.4の主要な変更点（旧版からの差分）を社内でレビューし、必要であれば当社名でパブリックコメントを提出することを検討。
- 既存のOTセキュリティ提案書・アセスメント手法をRev.4の構成に合わせて更新する準備を開始。

### 1-2. Microsoft Azure API Management「Classicティア」の認証情報窃取バグ、ノルウェーのエネルギー企業への攻撃に関連

- 出典: 複数メディア報道のまとめ（1Passwordおよび週間セキュリティニュースのまとめ記事経由で確認、Microsoft公式発表の直接確認は未了）
- URL: （二次情報源、個別記事URL未特定。Microsoft Security Response Centerの公式発表の直接確認を推奨）
- 公開日: 緩和策デプロイ 2026-11-19（報道は11月第4週）

**要約（3行以内）**
Azure API Managementの「Classic」ティアに存在した脆弱性により、保存されていたAPI認証情報が外部から窃取可能な状態にあったことが判明。Microsoftは11月19日に緩和策を適用しましたが、すでに窃取済みの認証情報自体は無効化されないとされ、同脆弱性はノルウェーのエネルギー企業への攻撃と関連付けられています。

**やさしい要約**
クラウド上でAPI（システム同士をつなぐ仕組み）を管理するMicrosoftのサービスに弱点があり、そこから「合鍵」にあたるアクセス情報が盗まれてしまいました。修正版は出ましたが、すでに盗まれた合鍵自体は自動的には無効にならないため、使っていた側が自分で鍵を替える必要があります。

**当社ビジネスへの影響**
- エネルギー・電力など重要インフラ事業者がAzureのAPI Management（特にClassicティア）を利用している場合、既に窃取された認証情報が残存しているリスクがあり、**セキュリティアセスメント**（クラウド/IT-OT境界の認証情報棒卸）の提案機会。
- IT（クラウドAPI管理）からOT（エネルギー制御システム）への侵入経路になり得る事例であり、**Nozomi**によるIT/OT境界の異常検知・資産監視の訴求材料として有効。

**推奨アクション**
- Azure API Management（特にClassicティア）を利用する顧客に対し、保存済みAPIキー・認証情報のローテーションを推奨する注意喚起を準備。
- 本件の一次情報（Microsoft Security Response Center発表）を次回調査で確認し、詳細を補完する。

### 1-3. フランス政府、イラン革命防衛隊（IRGC）系「Shahid Kaveh」部隊による冷蔵設備サイバー攻撃を正式非難、EUが対応協議

- 出典: The Record, govinfosecurity.com, SCMP等（複数報道の一致）
- URL: https://therecord.media/france-blames-iran-for-fridge-cyberattacks ／ https://www.govinfosecurity.com/france-blames-iran-for-cyberattacks-on-supermarkets-a-33345
- 公開日: 2026-11-09〜10（帰属発表）、EU外相級協議は11月下旬（直近）に予定

**要約（3行以内）**
フランス政府は10月に発生したフランス国内約700拠点のスーパーマーケットの冷蔵設備を停止させたサイバー攻撃について、イラン革命防衛隊（IRGC）傘下のサイバー部隊「Shahid Kaveh」の犯行と正式に断定しました。同部隊は、米国の水道事業者に対するOT攻撃（PLC制御系への侵入）にも関与したとされる組織と同一であり、EU外相級会合で対応が協議されています。

**やさしい要約**
フランスのスーパーの冷蔵庫を一斉に止めてしまったサイバー攻撃が、イラン政府に近い軍の部隊によるものだとフランス政府が正式に認定しました。同じ部隊はアメリカの水道施設を狙った攻撃にも関わっているとされ、ヨーロッパ各国が今どう対応するか話し合っています。

**当社ビジネスへの影響**
- 国家が関与する攻撃者が冷蔵・水道という「生活インフラのOT」を直接標的にしている実例であり、**Nozomi**によるOT異常検知・**セキュリティアセスメント**（OT資産のインターネット露出点検）の必要性を裏付ける強力な事例。
- 食品・流通・水道など、これまでOTセキュリティ投資の優先度が低かった業種への営業アプローチの好材料。
- リモート保守・遠隔監視経路が攻撃の侵入口になりやすいとされ、**Dispel**（セキュアリモートアクセス）の提案余地も大きい。

**推奨アクション**
- 食品・流通・水道・エネルギー等、これまで接点の薄かった業種の既存・見込み顧客へ、本事例を引用した注意喚起・提案を検討。
- 同部隊（Shahid Kaveh）の既知の攻撃手口（インターネット露出PLC、リモート保守経路の悪用等）をまとめた簡易ブリーフィング資料の作成を推奨。

### 1-5. Trellix「2026年11月版 OT脅威レポート」公表、水道・下水道セクターへの直接制御系侵入クラスターを最重要動向と指摘

- 出典: Trellix Advanced Research Center
- URL: https://trellix.com/advanced-research-center/threat-reports/ot-threat-report-nov-2026/
- 公開日: 2026年11月（対象期間は2026年4月〜9月）

**要約（3行以内）**
Trellixが公表した最新のOT脅威レポートでは、2026年4月〜9月の期間に政府機関が確認した「米国水道・下水道セクターの制御システムへの直接侵入」のクラスターが最も重大な動向として挙げられています。ランサムウェア活動の約3割がOTに影響を及ぼす攻撃に関連しているともされ、IT/OT境界を越えた攻撃の常態化が指摘されています。

**やさしい要約**
セキュリティ専門企業の調査によると、この半年で最も深刻だったのは「水道施設の制御システムそのものに直接侵入された」事例が相次いだことです。また、ランサムウェア攻撃の約3件に1件は、工場やインフラの制御システムにも影響を与えていました。

**当社ビジネスへの影響**
- ランサムウェアとOT攻撃の関連性データは、IT部門向けランサムウェア対策とOT部門向け対策を統合提案する根拠として、**セキュリティアセスメント・コンサル**全体の訴求に活用可能。
- 水道・下水道セクターの直接侵入クラスターは、同セクター向けの**Nozomi**（監視・検知）・**Dispel**（リモートアクセス保護）提案の裏付けデータとして有用。

**推奨アクション**
- 本レポートの主要統計（OT影響ランサムウェア比率、水道セクター侵入件数等）を営業資料・ニュースレターに引用することを検討。
- 水道・下水道事業者向けのテンプレート提案書を用意し、本レポートを引用資料として添付。
