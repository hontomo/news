### 1-1. Schneider Electric「Modicon M580」PLCに認証バイパスの重大脆弱性（CVE-2026-3869、CVSS 9.2）

- 出典: SecurityWeek（ICS Patch Tuesday報道）
- URL: https://www.securityweek.com/ics-patch-tuesday-schneider-electric-siemens-fix-critical-flaws/
- 公開日: 2026-09-09

**要約（3行以内）**
Schneider Electricは月例のICSセキュリティアドバイザリで、Modicon M580およびM580 SafetyのPLCに認証アルゴリズムの重大な欠陥（CVE-2026-3869、CVSS 9.2）を公表しました。アプリケーションレベル4.00未満（Safetyは4.20未満）の全機種が対象で、悪用されると認証を回避してシステムを完全に掌握される恐れがあります。現時点で実悪用は確認されていませんが、Safety用途の機器は検証・変更管理に時間を要するため、パッチ適用までの期間が長期化する懸念があります。

**やさしい要約**
工場やプラントの心臓部にあたる制御装置「PLC」の一種に、正しいパスワードなどを使わなくても入り込めてしまう欠陥が見つかりました。安全システムに使われる機種も対象のため、慎重な確認作業が必要で、すぐには修正パッチを当てられない現場が多いと見られています。

**当社ビジネスへの影響**
- Modicon M580は製造業・水処理・エネルギー分野で広く使われており、**Nozomi**によるOT資産可視化・異常検知の訴求材料として非常に有効。
- パッチ適用に時間がかかる前提のため、当該セグメントを「見えなくする」「識別ベースでアクセス制御する」といった代替緩和策の提案機会があり、**Dispel**（セキュアリモートアクセス）や**セキュリティアセスメント・コンサル**によるネットワークセグメンテーション支援の需要につながる。
- 変更管理・検証プロセスの負荷が高いため、設定・バージョン管理を支援する**Octoplant**の価値訴求にも直結。

**推奨アクション**
- Schneider Electric Modicon M580/M580 Safetyを保有する既存顧客へ、影響バージョンの確認とパッチ計画の緊急案内を実施。
- パッチ適用までの暫定策として、該当セグメントのネットワーク分離・アクセス制御強化を提案。

### 1-2. Siemens、ICS Patch Tuesdayで9件のアドバイザリ公開（4件が重大、保護リレー・産業用エッジ管理等）

- 出典: SecurityWeek（ICS Patch Tuesday報道）
- URL: https://www.securityweek.com/ics-patch-tuesday-schneider-electric-siemens-fix-critical-flaws/
- 公開日: 2026-09-09

**要約（3行以内）**
Siemensは月例のセキュリティアドバイザリを9件公開し、うち4件が重大（Critical）レベルの脆弱性でした。対象製品にはReyrolle 7SR5保護リレー、Open Interface Services、Industrial Edge Management、SIMOVE Fleetmanager/SIPLANTが含まれ、電力・製造業の運用に直結する製品群が広く影響を受けています。

**やさしい要約**
電力設備を守る保護装置や、工場のIT/OT連携を担う管理システムなど、Siemens製の重要な機器・ソフトに複数の深刻な弱点が見つかりました。放置すると設備の誤動作や不正操作につながる恐れがあります。

**当社ビジネスへの影響**
- Siemens製品を含む顧客の資産棚卸・パッチ管理支援として**セキュリティアセスメント**の提案余地が大きい。
- 産業用エッジ管理システムへの脆弱性は、IT/OT統合監視を行う**Nozomi**の適用範囲を訴求する好材料。
- 保護リレー等、稼働継続性が最優先される機器への対応は、稼働を止めずに脅威検知を行う**Nozomi**のパッシブ監視アプローチの強みと合致。

**推奨アクション**
- Siemens製品（特にReyrolle保護リレー、Industrial Edge Management）を利用する顧客に個別の脆弱性通知を実施。
- 重大度の高い4件について優先パッチ適用計画の策定を支援。

### 1-3. AVEVA「Pipeline Integrity Monitor」にハードコード鍵・脆弱なパスワードハッシュ等の脆弱性（CVE-2026-81821〜81824）

- 出典: CISA ICS Advisories（ICSA-26-253-01）
- URL: https://www.cisa.gov/news-events/ics-advisories/icsa-26-253-01
- 公開日: 2026-09-09/10

**要約（3行以内）**
AVEVAのパイプライン完全性監視ソフト「Pipeline Integrity Monitor」（2025_SP1_P1 build 7.1.9580.8513以下）に4件の脆弱性が判明。ハードコードされた暗号鍵（CVE-2026-81821、CVSS 8.4）や脆弱なMD5パスワードハッシュ（CVE-2026-81822、CVSS 8.4）により、機密情報の復号や管理者パスワードの解析につながる恐れがあります。ベンダーは2025 SP1 P2セキュリティ更新への適用と古いプロジェクトファイルの移行を推奨しています。

**やさしい要約**
石油・ガスなどのパイプラインの状態を監視するソフトに、暗号の鍵が固定値のまま埋め込まれていたり、パスワードの保管方法が古く弱かったりする欠陥が見つかりました。悪用されると管理者権限を奪われる可能性があります。

**当社ビジネスへの影響**
- パイプライン事業者など重要インフラ顧客への注意喚起・アセスメント提案の切り口として活用可能。
- ハードコード鍵・脆弱なハッシュという「設計上の根本的な弱点」は、導入前の**セキュリティアセスメント**（設計レビュー）の重要性を訴求する好例。
- 監視ソフト自体が攻撃対象となる点は、**Nozomi**による監視系ネットワークトラフィックの異常検知の必要性を補強。

**推奨アクション**
- AVEVA Pipeline Integrity Monitorの利用有無を顧客に確認し、該当する場合はセキュリティ更新の適用を案内。
- 古いプロジェクトファイルの移行作業支援を提案。

### 1-4. CISA ICS Advisory：産業用IPカメラ「CareCam Pro」にハードコード認証情報（ICSA-26-251-01）

- 出典: CISA ICS Advisories
- URL: https://www.cisa.gov/news-events/ics-advisories/icsa-26-251-01
- 公開日: 2026-09-08

**要約（3行以内）**
産業・施設監視用途で使われるIPカメラ「CareCam Pro」に、ハードコードされた認証情報が組み込まれていることが判明しました。攻撃者がこの認証情報を悪用すれば、機器への完全なアクセス権を取得し、映像の窃取や設定変更が可能になります。工場・重要施設のフィジカルセキュリティ監視に用いられるIoT/OT境界機器が対象です。

**やさしい要約**
工場や施設を見守る監視カメラに、誰でも使える「裏口パスワード」のようなものが最初から組み込まれていました。悪用されると監視映像を盗み見られたり、カメラを乗っ取られたりする恐れがあります。

**当社ビジネスへの影響**
- OT環境に隣接するIoT機器（監視カメラ等）の資産可視化ニーズを示す事例として、**Nozomi**のIT/OT/IoT統合監視の訴求に活用可能。
- ハードコード認証情報という初歩的な設計不備は、導入前デバイス評価を含む**セキュリティアセスメント**サービスの必要性を裏付ける。

**推奨アクション**
- CareCam Pro等、産業施設向け監視カメラの利用有無を顧客に確認し、ネットワーク分離・認証情報変更の可否をベンダーに確認するよう案内。

### 1-5. オランダNCSC、Check Point VPN機器の重大脆弱性（CVE-2026-85102/85103、CVSS 9.8）についてOTネットワークへの波及リスクを警告

- 出典: Security Boulevard「Daily OT Security News」（オランダNCSC公表内容の報道）
- URL: 一次情報未特定（NCSC公表内容を報じた集約記事に基づく。CISA/NCSC一次ページへのアクセスが本環境ではブロックされたため未検証）
- 公開日: 2026-09-09〜13（Check Pointによるパッチ公開は9/9、NCSC警告は同週）

**要約（3行以内）**
オランダの国家サイバーセキュリティセンター（NCSC）は、Check Point Security Gatewayの未認証リモートコード実行の重大脆弱性（CVE-2026-85102、CVE-2026-85103、CVSS 9.8）について、近く実悪用が始まる可能性が高いと警告しました。Check Pointは9月9日にパッチを公開済みで、NCSCはサイト間VPNのアクセス元を信頼済みIPアドレスに制限するよう推奨しています。

**やさしい要約**
社内ネットワークと外部をつなぐVPN機器に、パスワードなしでも乗っ取れてしまう重大な欠陥が見つかりました。この種の機器はOT（工場やインフラの制御システム）ネットワークへの入口としても使われることが多く、専門機関が「近いうちに悪用が広がる」と注意を呼びかけています。

**当社ビジネスへの影響**
- VPN機器はOTネットワークへのリモートアクセス経路として利用されるケースが多く、境界防御の脆弱性はOT環境への波及リスクに直結。セキュアなリモートアクセス基盤である**Dispel**への切り替え提案の好材料。
- VPN経由の侵入が疑われる場合の異常検知として**Nozomi**による監視の価値を訴求可能。
- 本件は一次情報での裏取りが未完了のため、社内共有時は「要検証」である旨を明記することを推奨。

**推奨アクション**
- Check Point Security Gatewayを利用し、かつOTネットワークへのVPN接続経路を持つ顧客に対し、パッチ適用状況とアクセス制限設定の確認を優先的に案内。
- 本件のCISA/NCSC一次情報を次回調査で改めて確認し、詳細を裏取りする。
