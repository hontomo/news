## 1. OTセキュリティ関連ニュース（5件）

### 1-1. CISA ICS Advisory：組込みTCP/IPスタック「lwIP」に重大脆弱性2件（CVE-2026-87121, CVE-2026-91018）

- 出典: CISA ICS Advisories（ICSA-26-265-01, ICSA-26-265-02）
- URL: https://www.cisa.gov/news-events/ics-advisories/icsa-26-265-01 ／ https://www.cisa.gov/news-events/ics-advisories/icsa-26-265-02
- 公開日: 2026-09-22

**要約（3行以内）**
組込み機器で広く使われるオープンソースTCP/IPスタック「lwIP」（v2.0.1〜2.2.1）に、MQTTクライアント機能のバッファオーバーフロー（CVE-2026-87121、CVSS 9.8）とAPI二重解放（CVE-2026-91018、CVSS 8.8）が発見されました。前者は攻撃者に機器上での任意コード実行を許す恐れがあり、化学、通信、重要製造業、エネルギー、金融、医療、運輸、上下水道など、ほぼ全ての重要インフラセクターに影響します。

**やさしい要約**
工場やビル、家電、産業機器など「インターネットにつながる小さな機械」の多くが内部で使っている共通の通信部品（lwIP）に、重大な欠陥が2つ見つかりました。この部品は非常に多くのメーカー・製品で使われているため、影響範囲が特に広いのが特徴です。

**当社ビジネスへの影響**
- lwIPは特定ベンダーに紐づかない共通コンポーネントのため、顧客環境のどの機器が該当するか把握しづらい典型例。**Nozomi**のOT/IoT資産可視化により組込みスタックのバージョン特定・影響範囲の洗い出しを支援できる好機。
- パッチ適用が困難なレガシー・組込み機器が多いと想定され、ネットワークセグメンテーションやアクセス制御を含む**セキュリティアセスメント・コンサル**の提案余地が大きい。
- 直接パッチできない機器への緩和策として、**TXOne**のOT向けネットワーク防御・仮想パッチ提案が有効。

**推奨アクション**
- 主要顧客に対し「自社製品・OT機器にlwIPが組み込まれていないか」の確認を促す注意喚起の配信。
- ベンダーからのファームウェア更新提供状況を継続モニタリングし、パッチ提供までの間はネットワーク分離・監視強化を提案。

### 1-2. CISA ICS Advisory：オープンソースPLC「OpenPLC Runtime v3」にセッションハイジャック脆弱性（EOL製品）

- 出典: CISA ICS Advisories（ICSA-26-265-09）
- URL: https://www.cisa.gov/news-events/ics-advisories/icsa-26-265-09
- 公開日: 2026-09-22

**要約（3行以内）**
オープンソースPLCソフト「OpenPLC Runtime v3」のWebインターフェースにクロスサイトスクリプティング（CWE-79）の脆弱性が見つかり、攻撃者がセッションCookieを乗っ取ってオペレーター権限のリクエストを送信できます。結果としてPLCおよびそれが制御する物理プロセスを乗っ取られる恐れがあります。対象はv3全体で、開発元は既にEOL（保守終了）としており、後継のv4へのアップグレードを推奨しています。

**やさしい要約**
無料で使える「PLC」（工場の機械を制御する小さなコンピュータ）向けソフトの管理画面に欠陥が見つかり、悪意あるページを開かせるなどの方法で機械そのものを乗っ取られる可能性があります。しかも、このソフトはメーカーによる修正提供が既に終了しており、新しいバージョンへの移行以外に根本的な対策がありません。

**当社ビジネスへの影響**
- コスト重視の中小製造業やラボ・教育現場でOpenPLCのような無償OSS PLCが使われるケースがあり、資産台帳に載っていないことが多い。**Nozomi**のOT資産発見機能の訴求材料として有効。
- EOL製品でありパッチが提供されないため、**セキュリティアセスメント**によるOSS/野良資産の棚卸しと、**TXOne**による代替的な防御（ネットワーク分離・異常検知）の組み合わせ提案が有効。

**推奨アクション**
- 顧客のOT資産棚卸しにOSSベースのPLC・SCADAコンポーネントも含めるよう、アセスメント項目の見直しを検討。
- OpenPLC v3を使用している顧客には、v4への移行またはネットワーク分離による緩和を提案。

### 1-3. Siemens、2026年9月22日に大量のICSアドバイザリを公開（Industrial Edge Management認証バイパス、Siveillance Control root権限奪取など）

- 出典: CISA ICS Advisories（ICSA-26-265-03, -04, -05, -06, -07, -08）

- 公開日: 2026-09-22

**要約（3行以内）**
Siemensは同日、Industrial Edge Management（認証バイパスによる完全アカウント乗っ取り、CWE-640。ファイアウォールでの緩和は8/26、修正版は9/2提供済み）、Siveillance Control／Control Pro（Open Interface Servicesの任意ファイルアップロードによりOISサーバでroot権限取得、CVE-2026-50093）、SIPLUS/SIMATIC系HMI複数製品群の「Copy Fail」脆弱性、Desigo CC（不正な図面ファイルによるクライアント側コード実行）等、計6件のアドバイザリを一括公開しました。対象は重要製造業、エネルギー、上下水道、化学、商業施設など多岐にわたります。

**やさしい要約**
大手産業機器メーカーのシーメンスが、同じ日に複数の製品（工場のIoT管理システム、監視カメラ制御システム、操作パネルなど）について「悪用されるとシステムを乗っ取られる可能性がある」欠陥をまとめて公表しました。特に「メールの本人確認なしにパスワードをリセットしてアカウントを乗っ取れる」問題と、「ファイルをアップロードするだけで管理者権限を取得できる」問題は深刻です。

**当社ビジネスへの影響**
- Siemens製品は国内外の製造業で広く導入されており、該当製品を使用する既存顧客への影響確認が急務。**Nozomi**によるSiemens資産の特定・パッチ状況の可視化が直接的な提案ポイント。
- Industrial Edge Managementの認証バイパスはリモート管理基盤の乗っ取りに直結するため、**Dispel**によるゼロトラスト型セキュアリモートアクセスへの切替提案の好機。
- 設定変更・パッチ適用履歴の管理という観点で**Octoplant**（構成管理・変更検知）の価値を訴求できる事例。

**推奨アクション**
- Siemens製品（Industrial Edge Management、Siveillance Control、SIPLUS/SIMATIC HMI、Desigo CC）の利用有無を顧客ごとに確認し、該当があれば緊急パッチ適用状況のヒアリングを実施。
- 特にIndustrial Edge Managementは既に修正版が出ているため、未適用の顧客には最優先での適用を推奨。

### 1-4. CISA、実攻撃で悪用されたZyxel GS1900スイッチの脆弱性をKEVカタログへ追加（約1,000台が侵害済み）

- 出典: CISA Known Exploited Vulnerabilities Catalog / Help Net Security / The Hacker News
- URL: https://www.cisa.gov/news-events/alerts/2026/09/21/cisa-adds-one-known-exploited-vulnerability-catalog ／ https://www.helpnetsecurity.com/2026/09/22/zyxel-switches-cve-2026-7273-vulnerability-exploited/
- 公開日: 2026-09-21〜22

**要約（3行以内）**
Zyxel GS1900シリーズスイッチのスタックバッファオーバーフロー脆弱性（CVE-2026-7273、CVSS 8.8）がCISAのKEV（既知の悪用済み脆弱性）カタログに追加されました。細工したHTTPリクエストによりLAN内の権限なし攻撃者がOSコマンドを実行可能で、9月17日頃から中国語話者とみられる攻撃者が48カ国・約996台のスイッチを侵害しデータを窃取したことが確認されています。パッチは6月16日提供済み。米連邦機関には9月25日までの対応が義務付けられました。

**やさしい要約**
オフィスや工場のネットワークでよく使われるネットワークスイッチ（Zyxel製）に欠陥が見つかり、既に世界中で約1,000台が実際にハッキングされ情報を盗まれていたことが判明しました。修正プログラムは3カ月以上前から出ていましたが、適用が追いついていなかったことが被害拡大の一因です。

**当社ビジネスへの影響**
- IT/OT境界や工場内ネットワークにも設置されがちなスイッチ製品であり、**Nozomi**によるネットワーク機器を含む資産可視化・脆弱性管理の訴求材料。
- 「パッチは3カ月前から出ていたが被害が拡大」という典型的なパッチ運用の課題を示す事例で、**セキュリティアセスメント**（資産棚卸＋パッチ適用状況の定期監査）の必要性を裏付ける。

**推奨アクション**
- Zyxel GS1900シリーズを利用している顧客リストの洗い出しとパッチ適用状況の緊急確認。
- 併せて、ネットワーク機器全般のパッチ管理プロセスの見直しを提案。

### 1-5. NIST、OTセキュリティガイド「SP 800-82」の大幅改訂ドラフト（Rev.4）を公開

- 出典: NIST CSRC / Industrial Cyber
- URL: https://csrc.nist.gov/pubs/sp/800/82/r4/ipd ／ https://industrialcyber.co/nist/nist-sp-800-82r4-draft-expands-ot-security-guidance-with-zero-trust-csf-2-0-consequence-driven-risk-management/
- 公開日: 2026-09-21

**要約（3行以内）**
NISTがOTセキュリティの代表的ガイドライン「SP 800-82」の改訂版（Rev.4）初期公開ドラフトを発表しました。Cybersecurity Framework 2.0への対応を軸に再構成し、資産管理・監視検知・ゼロトラストに関する指針を拡充。対象範囲も産業制御システムに加え、ビル管理システム、貨物鉄道、海事、上下水道、IIoT、クラウド連携まで拡大しています。意見募集は2026年11月30日まで。

**やさしい要約**
アメリカの政府機関（NIST）が、工場や重要インフラのセキュリティ対策の「教科書」となるガイドラインを大きく改訂する案を発表しました。最新の考え方である「ゼロトラスト」（何も信頼せず都度確認する仕組み）を重視し、対象も工場だけでなくビルや鉄道、水道、クラウドまで広げています。

**当社ビジネスへの影響**
- SP 800-82は**セキュリティアセスメント・コンサル**サービスの評価基準・提案フレームワークとして広く参照されており、改訂内容（ゼロトラスト・資産管理強化）は自社サービスメニューの見直し・訴求ポイントの更新材料となる。
- ゼロトラスト型リモートアクセスへの言及拡大は**Dispel**、資産管理・監視の強化は**Nozomi**の提案に直結。

**推奨アクション**
- ドラフト内容（特にゼロトラスト・資産管理・監視検知の章）を精査し、自社アセスメントメニュー・提案書のアップデートに反映することを検討。
- 意見募集期間中（〜11/30）に業界団体経由でのコメント提出も選択肢として社内で検討。

## 付記：調査上の制約

- 本セッションの実行環境では、CISA、SecurityWeek、Security Affairs、The Record、JPCERT/CC、JVN、IPA、NISC(cyber.go.jp)、ITmedia、Trend Micro、Unit42、Nozomi Networks、Dark Reading、Secomea等、指定ニュースサイトの大半への直接アクセス（WebFetch）が `EGRESS_BLOCKED`（ネットワークegressプロキシによるブロック）となりました。本レポートはWeb検索結果と複数媒体の突き合わせによる確認に基づいており、一次情報での完全な裏取りができていない項目が含まれます。
- Nozomi Networks公式ブログ（英語版・日本語版）、Secomeaブログについては、調査期間内（2026-09-20〜22）の新規公開記事は確認できませんでした。JNSA、ASCII.jp、Nikkei xTREND、BBC、IMARC Group、jiji.comについても、OTセキュリティに直接関連する新規記事は確認できませんでした。
- Cisco Secure FMC・Arista VCOの脆弱性悪用、Zyxelスイッチの実攻撃など一部の項目は、厳密には「重要インフラ・OT向け」に限定されないIT寄りのニュースですが、ネットワーク管理基盤の乗っ取りがOT環境への波及経路になり得るため、影響の大きさを鑑みて第2部（業界全体ニュース）に整理しています。
