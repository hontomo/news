### 1-1. フランス大手スーパー各社、産業用冷凍機コントローラ（Danfoss製）へのサイバー攻撃で在庫廃棄・一部火災

- 出典: Security Affairs / CBS News / ABC News (Australia) / Facilities Dive / TechNadu（複数媒体で概ね一致）
- URL: https://securityaffairs.com/200863/hacking/hackers-cranked-french-supermarkets-freezers-up-to-50-degrees-causing-hundreds-of-stores-to-lose-their-stock.html ／ https://www.cbsnews.com/news/cyberattack-supermarkets-refrigerators-france-fires-food-losses/ ／ https://www.facilitiesdive.com/news/hack-of-danfoss-refrigeration-controllers-in-europe-causes-tens-of-millions/832832/
- 公開日: 2026-10-12〜13（攻撃発生は10月11〜12日夜間とされる）

**要約（3行以内）**
フランスのCarrefour、Intermarché、Monoprix、Leclerc、Cooperative Uなど数百店舗で、Danfoss製の冷凍機コントローラ（AK-SM800、AK-SC355）が遠隔から不正操作され、強制デフロストと温度設定の改ざんにより庫内温度が約50℃まで上昇。冷凍・冷蔵在庫の廃棄（一部店舗で約5万ユーロ相当）に加え、一部では火災も発生しました。フランス当局（ANSSI）は認証バイパスやコード実行を許す既知の脆弱性の悪用を指摘しており、対象機器の多くはセキュリティ更新が提供されない旧世代品でした。影響はスペイン・ポルトガル・ポーランド・ドイツ・ベルギーにも及ぶ可能性があるとされています。

**やさしい要約**
スーパーの冷凍庫を遠隔操作しているコンピュータが外部から乗っ取られ、わざと温度を上げられてしまいました。冷凍食品が全部ダメになったり、一部では火事も起きたりするなど、ITの話が実際の「モノ」に被害を及ぼした典型例です。

**当社ビジネスへの影響**
- 「ITではないが長年放置された産業用コントローラ」が実被害につながる好例であり、**Nozomi**によるOT/IoT資産の可視化・異常検知の価値訴求に直結。
- 対象機器が「セキュリティ更新提供終了（legacy）」だった点は、パッチが打てない資産に対する代替緩和策（ネットワーク分離、監視）を売り込む**セキュリティアセスメント・コンサル**の好材料。
- 小売・物流・食品業といった非製造業OT（冷凍・空調・ビル管理システム）への防御提案の切り口として、**TXOne**（エンドポイント/ネットワーク防御）、**Octoplant**（設定変更の検知・復旧）の訴求にも活用可能。

**推奨アクション**
- 小売・外食・物流業界の顧客に対し、冷凍・冷蔵設備や空調等のビル管理システム（BMS）がネットワーク的に分離・監視されているかの点検を提案。
- 同種のレガシー産業用コントローラ（遠隔監視機能付き）を保有する顧客へ、ベンダーのサポート終了状況の確認を呼びかけ。

### 1-2. CISA・FBI・NSA・国際パートナー：中国系サイバー企業「Integrity Technology Group」が重要インフラ（OT含む）への事前侵入を支援と公表

- 出典: CISA公式発表 / Industrial Cyber / BleepingComputer / The Register / Nextgov
- URL: https://www.cisa.gov/news-events/news/cisa-fbi-nsa-and-international-partners-warn-china-based-cybersecurity-company-enabling-threat ／ https://industrialcyber.co/cisa/cisa-fbi-and-nsa-expose-integrity-technology-groups-role-in-china-linked-attacks-on-critical-infrastructure/
- 公開日: 2026-10-08（共同注意喚起 AA26-281A）

**要約（3行以内）**
CISA・FBI・NSAおよび海外パートナー機関は、中国政府と関係を持つサイバー企業「Integrity Technology Group」が、政府機関・重要製造業・医療・IT等の重要インフラセクターを標的とする攻撃者にツールや基盤を提供していると公表しました。CISA幹部は、中国政府系アクターが将来の機能破壊を目的として**OTシステムを含む**重要インフラ網内に足場を築き続けていると明言。手口はボットネット、VPN基盤の悪用、Living-off-the-Land、監視の甘いエッジデバイスの悪用等で、Flax Typhoon・Red Juliett等との関連も指摘されています。FBIは関連ドメインの差し押さえも実施しました。

**やさしい要約**
中国政府とつながりのある「裏方」企業が、様々な攻撃グループに侵入用の道具や基盤を提供していることが公式に名指しされました。目的は「今すぐ何かする」のではなく、「将来いつでも重要な設備（工場や発電所などを含む）を止められるように、あらかじめ入り込んでおく」ことだとされています。

**当社ビジネスへの影響**
- 「将来の機能破壊に備えた事前侵入」という脅威像は、常時監視・異常検知の必要性を訴える**Nozomi**の最重要訴求ポイントの一つ。
- 「監視の甘いエッジデバイス」が侵入口とされている点は、リモートアクセス経路の集中管理・監査を行う**Dispel**の提案余地を示す。
- 国家支援型の長期潜伏リスクへの備えとして、**セキュリティアセスメント**（侵害有無の確認、IoC調査）や**TXOne**によるOTエンドポイント保護の提案機会。

**推奨アクション**
- 重要インフラ系顧客（製造・医療・政府関連）に対し、本注意喚起を引用した「侵入検知・IoC確認」の無償簡易チェックの提案を検討。
- エッジデバイス（VPNゲートウェイ、リモートアクセス機器等）の資産棚卸とファームウェア更新状況の確認を促す。

### 1-4. Palo Alto Networks「2026年版 重要インフラサイバーセキュリティ実態調査」：68%がOT資産のリアルタイム可視化を欠く

- 出典: Help Net Security / Industrial Cyber（Palo Alto Networks調査レポートに基づく）
- URL: https://www.helpnetsecurity.com/2026/10/07/ot-network-visibility-challenges/ ／ https://industrialcyber.co/threats-attacks/rising-significance-of-ot-asset-visibility-in-cybersecurity-resilience-across-critical-infrastructure/
- 公開日: 2026-10-07

**要約（3行以内）**
11か国・5セクター1,600人超のリーダーを対象とした調査で、**68%がOT資産の完全なリアルタイム可視性を持たない**こと、OT環境に接続する資産の平均23%が「管理外・監視困難」であること、52%がレガシーOTシステムを最大の可視化課題として挙げていることが判明。平均7種類のセキュリティツールを使用しているが59%が「運用がむしろ複雑化した」と回答し、95%がAIを用いた攻撃への懸念を表明しています。また、過去12か月で重大なセキュリティ侵害を経験した組織は59〜60%に達するとされています。

**やさしい要約**
工場や発電所などを守る会社に調査したところ、「自分たちの設備に何がつながっているか、リアルタイムで正確に把握できていない」ところが約7割にも上ることが分かりました。道具をたくさん使っても管理が複雑になりすぎて、むしろ対応が難しくなっているとの声も多いようです。

**当社ビジネスへの影響**
- 「OT資産の可視化不足」という調査結果そのものが**Nozomi**の価値提案の核心であり、提案書・営業資料に直接引用可能な統計データ。
- 「ツールが多すぎて複雑化」という課題は、統合的な可視化・監視基盤への乗り換え需要を示唆し、既存の複数ベンダーツールからの**アセスメント→Nozomi統合提案**という流れを後押し。
- AIを用いた攻撃への懸念（95%）は、AI時代のOT防御をテーマにしたセミナー・ホワイトペーパー等のマーケティング材料として活用可能。

**推奨アクション**
- 本調査の主要統計（68%、52%、59%、95%等）を営業資料・提案書のテンプレートに反映。
- 既存顧客向けに「現状のOT可視化レベル簡易診断」を無償または低価格で提供する企画を検討。

### 1-5. SonicWall SMA 1000（リモートアクセスゲートウェイ）に最大深刻度の事前認証SSRF、7月以降3件目でOT遠隔アクセス環境にも影響

- 出典: BleepingComputer / Cloud Security Alliance / Security Affairs / Help Net Security
- URL: https://www.bleepingcomputer.com/news/security/max-severity-sonicwall-sma1000-flaw-now-exploited-in-attacks/ ／ https://labs.cloudsecurityalliance.org/research/csa-research-note-sonicwall-sma1000-ssrf-cve-2026-102255-202/
- 公開日: 2026-10-06（パッチ公表）〜10-12（悪用観測報道）

**要約（3行以内）**
SonicWallのリモートアクセスゲートウェイ「SMA 1000」（モデル6210/7210/8200v）のWorkPlaceインターフェースに、CVSS 10.0の事前認証SSRF脆弱性（CVE-2026-102255）が発見されました。10月6日にパッチが公開されましたが、研究者のハニーポットでは内部CouchDBサービスを狙った攻撃とみられるリクエストが観測されており、同コンポーネントでは7月以降3件目の最大深刻度SSRFとなります。ベンダー・CISAは本稿執筆時点で「実悪用」を公式確認していませんが、悪用の可能性が高いとされています。

**やさしい要約**
社外から安全に社内システムへアクセスするための「門番」役の機器に、極めて深刻な欠陥が見つかりました。同じ部分の欠陥としては今年3回目で、すでに攻撃者が様子見のアクセスを試みている形跡があります。

**当社ビジネスへの影響**
- SMA 1000のようなリモートアクセスゲートウェイは、OT環境への遠隔保守アクセスにも利用されるケースがあり、同種のVPN/ゲートウェイ機器への依存リスクを示す事例として、**Dispel**（専用セキュアリモートアクセス）への切替提案の訴求材料になる。
- 同コンポーネントで短期間に重大脆弱性が繰り返し発生している点は、境界機器への依存を減らす設計（ゼロトラスト的リモートアクセス）の必要性を示す。

**推奨アクション**
- SonicWall SMA 1000を利用している、またOT環境への遠隔保守にVPN機器を使っている顧客へ、パッチ適用状況の確認と代替のセキュアリモートアクセス方式（Dispel等）の検討を提案。
